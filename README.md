# T+1 超短线选股系统

围绕「**热门概念题材** + **主力资金流向**」两大核心维度，为隔日超短（严格 T+1，今买明卖）提供股票筛选与操作指导。

## 核心逻辑

**题材找方向 → 资金定标的 → 情绪定时机**：选出处在热门题材中、且有主力资金流入的强势股，博取次日惯性高开/冲高的溢价。

## 指标体系（三维度打分，总分 100）

| 维度 | 分值 | 内容 |
|------|------|------|
| 题材 | 40 | 是否 top5 热门板块 + 题材阶段 + 是否龙头 |
| 资金 | 40 | 封板强度(涨停股)/主力净流入(非涨停) + 资金持续性 + 龙虎榜 + 量价 |
| 技术 | 20 | 均线多头 + 突破新高 + MACD |

**信号分级**：S（≥85 且涨停+主升）盘中追 / A（70-84）尾盘买 / B（55-69）观察 / C 放弃

## 市场情绪周期

涨停家数 + 连板高度 + 炸板回封率 → 冰点/发酵/主升/高潮/退潮，决定总仓位与空仓条件。

## 回测结论（最近 3 交易日，131 样本）

- 涨停股次日开盘平均溢价 **+2.91%**，胜率 **64%**
- **2 板是甜蜜点**：开盘溢价 +7.28%，胜率 80%
- **3 板+必须竞价/早盘卖**：收盘涨幅转负（-0.42%），冲高回落

## 目录结构

```
cc/
├─ backend/
│  ├─ config.py          # 所有阈值/权重/接口参数（回测校准集中于此）
│  ├─ fetcher/           # 东财接口封装 + 反爬（eastmoney.py / http_client.py）
│  ├─ indicators/        # 指标计算（sentiment/theme/capital/technical/scoring）
│  ├─ strategy/          # 策略引擎（entry/exit/risk）
│  ├─ api/               # FastAPI 接口（main/routes/service）
│  ├─ scheduler.py       # 盘中定时刷新
│  └─ backtest.py        # 隔日超短回测
├─ frontend/             # React + Vite 看板
└─ requirements.txt
```

## 快速开始

```bash
# 1. 后端
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn backend.api.main:app --port 8000

# 2. 前端（另开终端）
cd frontend
npm install
npm run dev        # 访问 http://localhost:5173
```

或一键启动：`./start.sh`

## 桌面应用（双击即用）

已生成 macOS 桌面图标 **「超短选股.app」**，双击即可启动整个系统并自动打开浏览器。

- **首次双击**：启动后端 → 自动打开 http://localhost:8000
- **再次双击**：弹窗选择「打开看板 / 停止系统 / 取消」
- **重新生成**（改代码后）：`bash scripts/build_app.sh`

> 原理：FastAPI 直接托管 `frontend/dist` 静态页面，单进程即可运行看板，无需单独启动前端 dev server。

## 使用说明

1. 打开看板，查看「情绪仪表盘」判断今日能否操作
2. 「题材热度」确认当前主线题材
3. 「候选股」查看打分排序与买入建议（S 盘中追 / A 尾盘买）
4. 点击个股查看详情（概念板块 / 技术形态 / 资金流）
5. 手动「刷新数据」可强制重新计算

## 风险提示

本系统仅供学习研究，不构成投资建议。超短线交易风险极高，所有权重/阈值为初版默认值，需经更长历史回测校准后方可用于实盘。
